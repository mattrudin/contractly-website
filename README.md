# Contractly website

Public website for Contractly in seven languages. Static HTML and CSS, with no JavaScript or tracking.

Published from the root of the `main` branch using GitHub Pages.

Website: https://mattrudin.github.io/contractly-website/

To update, regenerate the website in the app project with `python3 website/check.py`, then copy only the contents of `website/dist` here, including `.nojekyll`. Never copy app configuration or credentials.
